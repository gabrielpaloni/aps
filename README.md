## 📘 Project Theme: AGL Music Hub

**Objective:**
To develop a music management platform (streaming hub concept) that applies core concepts of web development, focusing on database integration and secure user authentication.

### 🎯 Key Features
* **Secure Authentication:** Implementation of a Login/Registration system using PHP sessions and `password_hash` for data security.
* **Database Integration:** Full CRUD (Create, Read) operations for user management using MySQL and Prepared Statements to prevent SQL Injection.
* **Dynamic Content:** Structured playlist and artist views with modular components (Header/Footer/Sidebar) for clean architecture.
* **Responsive UX:** Custom CSS with modern UI elements, including glassmorphism effects and modal-based logouts.

## 🚀 How to Run
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/gabrielpaloni/aps.git](https://github.com/gabrielpaloni/aps.git)
    ```
2.  **Setup Environment:**
    * Move the folder to your XAMPP `htdocs` directory.
    * Import the database schema from the `config` folder into your MySQL (phpMyAdmin).
3.  **Run:**
    * Start Apache and MySQL via XAMPP.
    * Access `http://localhost/aps-primeiro-semestre/` in your browser.
